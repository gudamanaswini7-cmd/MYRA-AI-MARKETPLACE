# Reelsly - short-video app prototype (Flask + vanilla JS)

Windows (VS Code terminal, PowerShell):
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000  (or press F5 in VS Code -> "Run Reelsly")

Post a reel with the + button. Delete data/db.json to reset.
